## 🚀 Core Focus

**Zero-knowledge tooling · privacy protocols · cross-chain infrastructure.**

I build ZK and cross-chain developer SDKs — Circom-based circuits, Solidity verifiers, and Rust/Move tooling — spanning Arbitrum, Avalanche, Polkadot, and beyond. Fifteen hackathon wins, including **ETHGlobal New Delhi** and **ETH India 2025**, backed a track record I've since carried into founding two active developer communities in India.
